# Security

Auto Typer uses `pynput` to observe keyboard input system-wide while practice mode is active. It does not store, transmit, or log keystrokes, but users should review the permission prompt and only run it from a trusted copy.

Close the practice window to stop the listener. Do not use the application for sensitive data entry while practice mode is active.

Please report security issues privately to the repository owner rather than opening a public issue with exploit details.
